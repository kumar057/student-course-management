What It Includes

  • 5 related database tables with primary keys and foreign keys.
  • Sample data for departments, students, instructors, courses, and enrollments.
  • Practice queries for joins, aggregates, subqueries, updates, deletes, views, procedures, and reports.
  • Safe transaction examples for update and delete operations.

How To Run

  1. Open MySQL 8.x.
  2. Run the SQL files from 01_create_database.sql to 11_reports.sql.
  3. Test the views and stored procedure calls included in the scripts.
  4. Use the reports file to analyze popular courses, departments, instructors, and semesters.

Relationships

  • Students belong to Departments.
  • Instructors belong to Departments.
  • Courses belong to Departments and Instructors.
  • Enrollments connect Students and Courses.

Concepts Practiced

  • CREATE, INSERT, SELECT, UPDATE, DELETE
  • JOIN, GROUP BY, ORDER BY, aggregate functions
  • Subqueries, views, stored procedures, transactions
